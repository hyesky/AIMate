# AIMate 信创合规与部署方案

## 开源许可策略

- 本体：**Apache-2.0**（宽松，支持私有化/闭源交付，保留版权声明即可；无 GPL/AGPL 传染）。
- 运行时直接依赖：aiohttp / pydantic / aiosqlite / cryptography / lark-oapi —— 均为宽松许可。
- 国内 IM 通道：飞书(lark-oapi) / 钉钉(alibabacloud-dingtalk) / 企微。
- 向量检索：RAG 内自带纯自研 BM25；稠密向量可对接内网 Embedding 网关（可选用国产向量库）。

## 涉外商用端点（默认不启用/可置空）

平台骨架不含任何强制回传遥测。凡是涉外商用默认值（如默认模型网关、更新检查等）
均应：
- 配置文件置空默认值；
- 对话模型指向**内网推理网关**（自建 vLLM/MLX 或国产推理服务）；
- Embedding 落**本机路径 / 内网向量服务**。

## 国密（信创等保）

- `security/audit.py` 提供 SM2/SM3/SM4 封装接口与占位实现（SM3 暂用 SHA-256 示意，
  SM4 暂用 HMAC 流占位）。
- **生产必做**：将占位替换为通过国密认证的实现 —— 推荐使用加密机/密码模块产品
  （或经 SM 认证的 gmssl / 高性能国密库），并完成 SM 算法一致性测试。
- AES 相关既有加密路径迁移到 SM4，摘要迁移到 SM3，签名迁移到 SM2。

## 信创软硬件适配概要

| 层 | 现状 | 信创适配 |
|---|---|---|
| OS | 跨平台 Python | 麒麟 / 统信 UOS / 欧拉 可跑（仅 Python 3.11+ 即可）|
| 数据库 | aiosqlite（自研层）| 可接 达梦 / 人大金仓 / OceanBase / openGauss |
| 向量库 | 内存 BM25 + 可选向量 | 可接 国产向量库或内网 Milvus 改造 |
| 国密 | 占位 | 置换为合规 SM2/3/4（等保测评项）|
| 模型 | 内网网关 | 可接 DeepSeek / 豆包 / Qwen 等国产模型 |

```
[端侧] 数字员工节点注册进管控台
[IM]   企微/钉钉/飞书 公司级通道
```
