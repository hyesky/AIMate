# AIMate 架构设计

## 分层

```
┌──────────────────────────────────────────────────────────────┐
│ 客户端 client/                                                │
│   网页工作台 (client/web)   办公/运维/业务智能体客户端          │
└──────────────────────────────┬───────────────────────────────┘
                               ▼
┌──────────────────────────────────────────────────────────────┐
│ 统一接入 gateway/                                             │
│   channels/  IM 通道：企微 / 钉钉 / 飞书                       │
│   auth/      认证授权（OpenAPI key / Anthropic key / IM 签名） │
│   api/       OpenAPI + Anthropic-API 开放集成                 │
└──────────────────────────────┬───────────────────────────────┘
                               ▼
┌──────────────────────────────────────────────────────────────┐
│ 服务端 Server（管理后端 + 运行时）                             │
│   agents/    数字员工 + Agent 池（人格/技能/记忆/模型绑定）     │
│   rag/       知识库：切分 → 向量化 → 召回（BM25+稠密 hybrid）   │
│   workflow/  DAG 工作流编排（并行执行、状态持久化）            │
│   skills/    Skill 市场 + 企业自建 + Curator 自沉淀策展        │
│   memory/    有界持久记忆 + 自我进化（add/replace/remove）     │
│   org/       成员组织 / 部门树 / RBAC / 邀请 / 导入            │
│   security/  审计 + 国密封装 (SM2/3/4)                         │
│   license/   .lic 有效期 + 功能 + 座位配额 门控                │
└──────────────────────────────────────────────────────────────┘
```

## 设计原则

1. **自研优先（路径 B'）**：借鉴开源蓝本的**架构思想**（人格注入、技能渐进披露、
   有界记忆、通道-调度-服务端分层）与**国产落地范式**（本地优先、内网推理网关），
   但**核心代码从零自研**，可宣称自主可控。
2. **私有化/内网部署优先**：管控台、对话、知识库、审计、Embedding 全部可落客户侧。
3. **多租户贯穿**：agent / memory / skills / org / license 全部按 tenant_id 隔离。
4. **自我进化**：Agent 可自沉淀技能 + 有界记忆跨会话保持；Curator 后台策展（只归档、不硬删）。
5. **合规可裁剪**：仅依赖宽松许可开源组件；涉外商用端点（若有）可置空、指向内网网关。

## 核心数据流

```
IM/OpenAPI/Anthropic-API
        │  GatewayAuth 认证 + RBAC
        ▼
   统一调度器 ──→ Agent（+SOUL+技能+记忆）
        │              │
        │              ├─→ rag.KnowledgeBase（召回）
        │              ├─→ workflow.Engine（编排）
        │              ├─→ memory.Manager（持久记忆写）
        │              └─→ skills.Curator（技能沉淀）
        ▼
    内网 LLM 网关（对话模型）/ 本机 Embedding
```
